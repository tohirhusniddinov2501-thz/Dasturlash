Amal (operator) va operand tushunchalariAmal (operator) — bir yoki bir nechta qiymat (operand) ustida ma'lum bir harakatni bajarib, yangi natija hosil qiluvchi belgi yoki kalit so'zdir. Masalan, $5 + 3$ ifodasida + — amal, $5$ va $3$ — operandlar, natija esa $8$ ga teng.Operandlar soniga ko'ra amallar turlarga bo'linadi:Unar amal — faqat bitta operand bilan ishlaydi (masalan: -yosh, yosh++).Binar amal — ikkita operand bilan ishlaydi (masalan: a + b, a * b).Ternar amal — uchta operand bilan ishlaydi (shart ? a : b).2. Console.WriteLine(a / b);           // 3 (butun son bo'linishi)
Console.WriteLine(a % b);           // 1 (bo'lishdan qolgan qoldiq)

double aniq = (double)a / b;        // 3.5 (turga oshkor keltirish orqali)
Console.WriteLine(aniq);

Ortirish va kamaytirish amallari (++, --)++ (inkrement) — o'zgaruvchi qiymatini $1$ taga oshiradi (yosh = yosh + 1 bilan bir xil).-- (dekrement) — o'zgaruvchi qiymatini $1$ taga kamaytiradi (yosh = yosh - 1 bilan bir xil).Ushbu unar amallarning ikki xil yozilish shakli mavjud:Prefiks shakl (++yosh): avval o'zgaruvchi qiymati $1$ taga oshiriladi, so'ng yangilangan qiymat ifodada ishlatiladi.Postfiks shakl (yosh++): avval o'zgaruvchining joriy qiymati ifodada ishlatiladi, so'ng qiymati $1$ taga oshiriladi.int yosh = 20;

Console.WriteLine(yosh++); // Avval 20 chiqadi, keyin yosh 21 bo'ladi
Console.WriteLine(yosh);   // 21
Console.WriteLine(++yosh); // Avval 22 bo'ladi, keyin shu 22 ekranga chiqadi

Qisqartirilgan qiymat berish amallari (Compound Assignment)O'zgaruvchining o'z qiymati ustida amal bajarib, natijani yana o'sha o'zgaruvchiga yozishni qisqa ko'rinishda ifodalash mumkin:AmalTo'liq yozilishiQisqa yozilishi=Oddiy qiymat berishyosh = 20;+=yosh = yosh + 5;yosh += 5;-=yosh = yosh - 5;yosh -= 5;*=narx = narx * 2;narx *= 2;/=narx = narx / 2;narx /= 2;%=son = son % 3;son %= 3;int ball = 70;
ball += 15; // ball = 70 + 15 -> 85
Console.WriteLine(ball); // 85

ball -= 5;  // ball = 85 - 5 -> 80
Console.WriteLine(ball); // 80
2. Turlarga keltirish (Type Casting)Bir berilganlar turidagi qiymatni boshqa turga o'tkazish casting deyiladi. Uning ikki xil usuli mavjud:Avtomatik (implicit) keltirish: Kichikroq diapazonli turdan kattaroq turga o'tishda ma'lumot yo'qolish xavfi bo'lmagani uchun C# buni avtomatik bajaradi (masalan: int $\rightarrow$ double).Oshkor (explicit) keltirish: Kattaroq yoki kasrli turdan kichikroq turga o'tishda qavs ichida maqsadli tur ko'rsatiladi: (tur)qiymat. Bunda kasr qismi yaxlitlanmaydi, balki kesib tashlanadi.double narx = 7.9;
int butun = (int)narx;   // Oshkor keltirish: natija 7 (8 emas!)
Console.WriteLine(butun);

int son = 5;
double avtomatik = son;  // Avtomatik keltirish: natija 5 (5.0)
Console.WriteLine(avtomatik);
3. Shartli amal (Ternary Operator)Shartli amal (? :) — bitta qatorda oddiy if-else konstruksiyasi vazifasini bajaruvchi uch operandli qisqa yozuv usuli.Sintaksisi:shart ? qiymat1 : qiymat2;
Agar shart rost (true) bo'lsa qiymat1, yolg'on (false) bo'lsa qiymat2 qaytariladi.int yosh = 16;
string natija = (yosh >= 18) ? "Kattalar" : "Voyaga yetmagan";
Console.WriteLine(natija); // Natija: Voyaga yetmagan
