O'zgaruvchi (Variable)O'zgaruvchi — dastur ishlashi davomida qiymati o'zgarishi mumkin bo'lgan, nomlangan xotira katakchasidir.E'lon qilish sintaksisi:tur nom = boshlangich_qiymat;
Bir xil turdagi bir nechta o'zgaruvchini vergul bilan ajratib bir qatorda e'lon qilish mumkin: int a = 1, b = 2;. O'zgaruvchiga keyinchalik yangi qiymat berilganda turi qayta yozilmaydi.int yosh = 20;
string ism = "Aziza";

Console.WriteLine(ism + " yosh: " + yosh); // Natija: Aziza yosh: 20

yosh = 21; // Qiymat yangilandi
Console.WriteLine(yosh); // Natija: 21
3. O'zgarmas (Constant)O'zgarmas — dastur davomida qiymati hech qachon o'zgarmaydigan nomlangan qiymat. U const kalit so'zi yordamida e'lon qilinadi.Kod ichida tushunarsiz "sehrli sonlar" (magic numbers) o'rniga mazmunli nom ishlatish imkonini beradi.const bilan e'lon qilingan qiymatni dastur davomida o'zgartirishga urinish kompilyatsiya xatosiga olib keladi.Yaxshi dasturlash odatiga ko'ra o'zgarmaslar katta harflar bilan yoziladi (PI, MAX_YOSH).const double PI = 3.14159;
double radius = 5;
double yuza = PI * radius * radius;

Console.WriteLine(yuza); // Natija: 78.53975

// PI = 3.14; // XATO! const qiymatini o'zgartirib bo'lmaydi
4. Izohlar (Comments)Izohlar — kod ichida yoziladigan, lekin kompilyator tomonidan e'tiborsiz qoldiriladigan va dastur bajarilishiga ta'sir qilmaydigan tushuntirish matnlaridir. Yaxshi izoh kodning nima qilayotganini emas, balki nega shunday yozilganini tushuntiradi.Bir qatorli izoh: // belgisidan boshlanib, qator oxirigacha davom etadi.Ko'p qatorli izoh: /* bilan ochilib, */ bilan yopiladi.// Talabaning yoshini saqlash uchun o'zgaruvchi
int yosh = 20;

/*
   Bu qism talaba haqidagi ma'lumotlarni
   ekranga chiqarish uchun ishlatiladi.
*/
Console.WriteLine(yosh); // Natija: 20
